Kanban Board is a simple web application created during a university Java course. At the beginning of the semester, each student received a randomly assigned project topic, and mine was a Kanban board.

The app allows users to create, edit, delete, and move tasks between To Do, In Progress, and Done columns. The backend was written in Java and connected to an Apache Derby database through JDBC.

It was a straightforward project, but a useful introduction to building a complete CRUD application, working with relational databases, and connecting a Java backend to a browser-based interface.
