Arkanoid Game Clone was the first game I ever created. It was built in C++ with SFML as a university project and recreated the core gameplay of the original Arkanoid.

The game includes all 33 levels, several brick types, power-ups, a boss fight, a level selector, and local high-score tracking. Levels are loaded from external text files, which made them easy to edit without changing the source code.

Since I was not using a game engine, I had to implement the main systems myself, including scene management, collisions, ball reflection, resource loading, and basic UI.

It was a simple project, but an important one for me. It was my first real introduction to game development and helped me understand how a game loop, rendering, input, collisions, and object-oriented game architecture work together.
