Serial Communication Protocols is a university desktop project focused on communication through RS-232 and RS-485 ports.

I created two simple Windows applications in C#: an RS-232 terminal and a simplified Modbus-style communication system with master and slave modes. The apps allowed data to be sent between serial ports, handled timeouts and transmission errors, and included basic message validation.

To test the project without physical hardware, I used virtual COM ports on my PC and connected the applications to each other. The setup worked as expected and gave me practical experience with serial communication, desktop development, and debugging low-level data exchange.
